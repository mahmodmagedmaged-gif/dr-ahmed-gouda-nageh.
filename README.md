# الموقع الطبي والمهني الرسمي للدكتور أحمد جودة ناجح
## Dr. Ahmed Gouda Nageh — Official Medical Portfolio & Patient Education Platform

موقع طبي ومهني متكامل فائق الدقة، مصمم ومطور خصيصاً للدكتور **أحمد جودة ناجح**، أخصائي الجراحة العامة والمناظير وجراحة السمنة والشرج، والحاصل على الزمالة البريطانية للجراحة العامة.
تم بناء الموقع بأحدث معايير الويب المتقدمة (HTML5 دلالي، CSS3 متقدم ونظام سمات داكن/فاتح، JavaScript أصيل بدون مكتبات ثقيلة)، مع دعم كامل ومتقن للغة العربية (RTL) مع إمكانية التبديل للغة الإنجليزية (LTR)، وجاهزية تامة وفورية للنشر عبر **GitHub Pages**.

## 🌟 ميزات الموقع الرئيسية (Key Features)

2. **عرض صورة الطبيب والتبديل التفاعلي (Dual Portrait Switcher)**:
   - عرض الصورة الحقيقية المعتمدة للدكتور أحمد جودة ناجح في غرفة العمليات بالزي الجراحي أثناء إجراء جراحة مناظير دقيقة.

4. **مكتبة التوعية الطبية الجراحية (Medical Education Library)**:

     - `الكل` — `جراحات السمنة` — `جراحات المناظير` — `الجراحة العامة` — `الشرج والمستقيم` — `تحضير ورعاية المريض`.

     1. ما هي عملية تكميم المعدة؟ (Sleeve Gastrectomy).
     2. متى قد يحتاج المريض إلى جراحة السمنة؟ (معايير مؤشر كتلة الجسم والحالات المصاحبة).
     3. ما الفرق بين الجراحة المفتوحة وجراحة المناظير؟
     4. كيف يستعد المريض للعملية الجراحية؟
     5. ما أهمية المتابعة بعد الجراحة؟

## 🚀 طريقة المعاينة والتشغيل محلياً (Local Preview)

الموقع مبني بالكامل كملفات ثابتة (Static Web Architecture)، ولا يتطلب أي خوادم معقدة لتشغيله:

### الطريقة الأولى: الفتح المباشر
- يمكنك النقر المزدوج على ملف `index.html` في مستكشف ملفات ويندوز ليفتح مباشرة في متصفحك الافتراضي (Chrome, Edge, Firefox, Safari).

### الطريقة الثانية: عبر خادم محلي مدمج في بايثون (موصى بها)
افتح موجه الأوامر (PowerShell أو Terminal) داخل مجلد المشروع، ثم نفذ:
```powershell
python -m http.server 8080
```
ثم افتح المتصفح على الرابط:
[http://localhost:8080/](http://localhost:8080/)

## 🌐 خطوات النشر على GitHub Pages (Deployment Guide)

المشروع مهيأ بالكامل للنشر الفوري والمجاني على **GitHub Pages**:

### الطريقة الأولى: عبر رفع الكود على مستودع GitHub جديد (Automated GitHub Actions)
1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub (مثلاً باسم: `dr-ahmed-gouda`).
2. افتح مجلد المشروع في جهازك واربطه بالمستودع وارفعه:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Dr. Ahmed Gouda Nageh Medical Portfolio"
   git branch -M main
   git remote add origin https://github.com/USERNAME/dr-ahmed-gouda.git
   git push -u origin main
   ```
3. توجه إلى إعدادات المستودع على GitHub: **Settings** > **Pages**.
4. تحت **Build and deployment** > **Source**:
   - اختر **GitHub Actions** (حيث تم إعداد ملف `.github/workflows/deploy.yml` تلقائياً ليقوم بالبناء والنشر فور كل دفع).
   - أو اختر **Deploy from a branch** وحدد فرع `main` والمجلد `/ (root)`.
5. سيصبح موقعك متاحاً فوراً على الرابط:
   `https://USERNAME.github.io/dr-ahmed-gouda/`
